# Оно тебе надо

«Оно тебе надо» — одностраничный сайт необычного аукциона, на котором представлены вещи и произведения искусства, когда-то недооценённые обществом, но впоследствии ставшие культовыми.

Проект выполнен по макету первого спринта Яндекс Практикума. На странице размещены обложка с названием аукциона, карточки лотов с описаниями, информация о концепции аукциона, навигация и контактные данные.

Сайт свёрстан на **HTML5 и CSS3** без использования JavaScript и сторонних библиотек. Для построения интерфейса используются семантическая разметка, CSS Grid и Flexbox. Оформление включает фоновые изображения, полупрозрачные оверлеи и локально подключённый шрифт Raleway.
